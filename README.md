# T2.6-Operaciones-Avanzadas-e-Integridad-de-Datos
Ejercicio 1: Búsqueda Lineal de Productos

En este ejercicio se desarrolló un programa en Java que permite registrar nombres de productos y sus respectivos precios utilizando arreglos paralelos. Posteriormente, el usuario ingresa el nombre de un producto para realizar una búsqueda lineal recorriendo el arreglo elemento por elemento hasta encontrarlo. Si el producto existe, se muestra su nombre y precio; caso contrario, se informa que no fue encontrado.

Ejercicio 2: Prevención de Buffer Overflow

En este ejercicio se creó un programa en Java que almacena números enteros en un arreglo y los recorre utilizando un ciclo for. Para evitar errores de desbordamiento de memoria, se utilizó numeros.length, garantizando que el ciclo no sobrepase el tamaño del arreglo. Además, se explicó mediante comentarios el error que ocurriría si se intenta acceder a posiciones inexistentes del arreglo.
